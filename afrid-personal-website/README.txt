AFRID MAHMUD JOY — PERSONAL WEBSITE

Included files:
- index.html: website content
- styles.css: visual styling (dark theme, responsive layouts)
- script.js: small helper for current year and navigation behavior
- cv.pdf: your CV for the Download CV links

Beginner deployment (GitHub + Vercel):
1. Extract this ZIP on your computer.
2. Create a GitHub account or sign in.
3. Create a new repository named personal-website (Public is easiest for first deployment).
4. Upload all files from the extracted afrid-personal-website folder to the repository root.
   Important: Upload index.html, styles.css, script.js, and cv.pdf directly, not the outer folder itself.
5. On Vercel, sign in with GitHub and choose Add New -> Project.
6. Import the personal-website repository. For this plain HTML/CSS/JS project, keep framework preset as Other and build command/output directory empty if Vercel permits; deploy.
7. After deployment, go to Project Settings -> Domains and check the assigned vercel.app address.
8. To claim afridmahmudjoy.vercel.app, set project name to afridmahmudjoy if that name is available.

Before making the website widely public:
- Add your own portrait photo in place of the placeholder (we can do this together).
- Confirm the email address is okay to display publicly.
- Add LinkedIn/GitHub/Instagram URLs only after you provide the exact links.
- Add real design samples and photography instead of the placeholder artwork.
